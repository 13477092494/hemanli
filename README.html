📋 工作台 11 个模块

🏠 工作台首页
今日营业额、本月利润、客户预约快到提醒、今日工作汇报（已完成/待进行/营收/客流）、快到期会员提醒。
📅 预约管理
状态分类（全部/待确认/已确认/已完成/已取消）。每条可编辑、确认、完成、取消、彻底删除，支持左滑删除不残留。
💰 报价开单
选中已备案客户或散客自填，自动按会员折扣算出应付价，自动累计积分（基础×会员倍率×项目倍率）。
👤 客户档案
含手机号、生日、会员卡/到期/余额、积分、来源。老客户可自由填写。右滑/左滑删除。
💳 会员管理
3 档默认（¥300享9.5折/¥500享9折/¥1000享8折），可自由增删等级。每个客户独立享折扣。
⭐ 积分中心
赚取规则（消费/推荐/分享/签到/注册）+ 兑换规则（卸甲/补色/护理/贴纸/抵扣/抽奖）+ 积分流水（可滑动删除）。
📊 营销管理
年/月利润、12个月营收柱状图、产品 TOP10、月度利润表、直播短视频选题。弹幕提醒预约快到。
📒 财务管理
记一笔（类型/金额/日期/项目/谁消费/备注）。自填列表，所有记录支持左滑删除。
🔗 链接抓取
粘贴抖音/小红书/淘宝/京东/拼多多/1688/微信/支付宝链接，自动识别平台预览，可直接保存为消费记录并关联客户。
🔔 通知中心
自定义通知（短信/微信/复制）+ 一键批量提醒：快到期会员、积分余额、今日生日、明日预约。
⚙️ 设置
店铺信息（名称/营业时间/预约间隔/提醒时长）+ 款式服务管理（每项可改价格/耗时/积分倍率）+ 二维码生成 + 数据导入/导出。

📱 客户扫码端 - 仅显示个人信息

🛡️ 隐私保护： 客户扫码进入后只能看到自己的预约、积分、会员卡。当日已约时段只显示时间，不显示其他客户姓名/款式/手机号，避免重复预约且不泄露隐私。
  • 首页：个人会员卡 / 积分 / 年卡到期 · 美甲时长参考（多本甲/甲片/千元款）· 营业时间（9:00-20:00）· 兑换规则 · 充值会员
  • 预约：选日期后自动显示当日空闲时段（灰色=已约不能选）· 点空闲格子直接选开始时间 · 填姓名/手机/款式/备注 · 提交后跳转"我的预约"
  • 我的预约：列出自己所有预约 · 状态显示（待确认/已确认/已完成/已取消）· 左滑取消
  • 会员中心：完整会员卡信息 + 积分余额 + 充值选项
  • 预约时间由店家控制：客户端只能从空余时段选开始时间，结束时间由店家按款式耗时确定
