📲 第一步：把工作台装到桌面（当 App 用）

应用已改造成 PWA（渐进式 Web 应用），打开后会自动提示安装。也可按下列方式手动添加：

iPhone
Safari
打开工作台网页 → 点底部 ⬆ 分享 按钮（方框加箭头）→ 往上滑找到 「添加到主屏幕」 → 命名「禾蔓里」→ 点右上角 添加。
桌面即出现粉色花朵图标，点开就是全屏 App（无浏览器地址栏）。
安卓
Chrome
打开工作台网页 → 点右上角 ⋮ 菜单 → 选 「安装应用」/「添加到主屏幕」 → 确认。
或直接点地址栏右侧的 📲 安装图标。
Windows
电脑
用 Chrome / Edge 打开工作台网页 → 点地址栏右侧 📲 安装（电脑图标） → 点「安装」。
或在 ⋮ → 应用 → 将此站点另存为应用。装好后开始菜单/桌面出现图标。
Mac
电脑
用 Chrome / Safari 打开 → Safari 选 文件 → 添加到「访达」程序坞；Chrome 点地址栏安装图标 → 安装。
App 会出现在启动台/程序坞。
💡 客户扫码进入的也是同一套界面（自动只显示预约/积分/会员），他们同样可以「添加到主屏幕」，得到自己的预约 App。店主 App 和客户 App 是同一个链接、同一个入口。

🔗 第二步：关于「永久固定链接」

当前工作台部署在云端沙盒里，沙盒休眠期间预览链接会失效，所以它不是永久链接。要获得真正 7×24 永久、免费、不变的链接，推荐把应用上传到你自己的静态托管（应用是纯前端单文件，部署极简）。

方案 A：GitHub Pages（免费永久，最推荐）

1
把下载的 zip 解压，得到 index.html、demo.html、manifest.webmanifest 等 10 个文件
2
登录 github.com → 新建仓库（如 hemanli）→ 把解压文件全部上传
3
仓库 Settings → Pages → Source 选 main 分支 / root → Save
4
几分钟后获得永久链接：https://你的用户名.github.io/hemanli/（加上 #customer 即客户端）

✅ 完全免费、永久稳定、HTTPS 加密、支持「添加到主屏幕」安装为 App

方案 B：任意静态托管（国内更快）

把解压文件夹整个上传到 阿里云 OSS / 腾讯云 COS / 七牛云 / 又拍云 / 自己的虚拟主机 的网站根目录，开启「静态网站托管」即得到一个永久域名。国内访问速度比 GitHub 更快。

方案 C：纯本地（最稳妥、零依赖）

解压后直接双击 index.html 用浏览器打开即可使用（数据存在本机浏览器里）。缺点：不能「添加到主屏幕」装成 App、换设备数据不共享。适合只用一台电脑的工作室。

💾 第三步：下载应用包

应用已打包成 hemanli-studio.zip（160KB，含全部 10 个文件）。下载后按方案 A/B/C 部署，或直接解压使用。

📦 包内文件：index.html（工作台空数据）、demo.html（带示例数据）、README.html（说明）、manifest.webmanifest、sw.js、icon.svg/192/512/180/maskable.png

⬇ 下载安装包 (zip) ▶ 打开工作台演示版 ▶ 打开客户端预览

🔄 数据备份提醒

所有数据存在浏览器本地（localStorage）。定期在「设置 → 数据管理 → 导出 JSON」备份，换设备或重装后「导入 JSON」恢复。部署到自己的托管后，同一设备同一浏览器数据会保留；换设备需重新导入。多人（店长+店员）共用时，请在同一台设备/浏览器上操作以保证数据一致。
